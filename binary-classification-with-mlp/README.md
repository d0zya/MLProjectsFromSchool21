# Полносвязная нейронная сеть с нуля и на PyTorch для бинарной классификации

В этом проекте исследуется задача бинарной классификации с использованием полносвязной нейронной сети (**MLP**), реализованной **с нуля**, а также с помощью **scikit-learn** и **PyTorch**.  
Основной акцент сделан на понимании того, как работает многослойный перцептрон на практике, сравнении собственной реализации с библиотечными решениями и анализе влияния функций активации и оптимизаторов на качество модели.

## Цель проекта

Цель этого проекта:
- реализовать полносвязную нейронную сеть с нуля,
- изучить, как работают прямой проход, обратное распространение ошибки и обновление весов,
- сравнить собственную реализацию с `scikit-learn` и `PyTorch`,
- исследовать влияние разных функций активации и оптимизаторов,
- проанализировать качество модели на задаче бинарной классификации.

## Датасет

В проекте используется датасет **Don’t Get Kicked** для предсказания риска покупки проблемного автомобиля.

Целевая переменная:
- является ли автомобиль рискованным / проблемным

Признаки включают:
- характеристики автомобиля,
- информацию, связанную с покупкой,
- категориальные и числовые признаки после предварительной обработки,
- подготовленные признаки для обучения нейросетевой модели.

## Что реализовано и исследовано в проекте

### С нуля
- MLP (Multilayer Perceptron)
- прямой проход
- обратное распространение ошибки
- обучение с помощью градиентного спуска
- разные функции активации
- разные оптимизаторы

### С использованием библиотек
- `MLPClassifier` из `scikit-learn`
- MLP на `PyTorch`

### Практические эксперименты
- сравнение собственной реализации с `scikit-learn`,
- исследование влияния `SGD` и `Adam`,
- исследование влияния `sigmoid`, `ReLU`, `LeakyReLU`, `tanh`,
- сравнение train / validation / test качества,
- анализ переобучения для разных конфигураций модели.

## Ключевые результаты

Основные выводы проекта:
- собственная реализация MLP показала конкурентное качество по сравнению с библиотечными реализациями,
- качество модели заметно зависело от выбора функции активации и оптимизатора,
- некоторые конфигурации модели показывали признаки переобучения,
- наилучшие результаты показали не все “самые сложные” настройки, а более устойчивые конфигурации,
- реализация на `PyTorch` подтвердила корректность общей архитектуры и пайплайна обучения.
