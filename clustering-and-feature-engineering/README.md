# Обучение без учителя: кластеризация и feature engineering

В этом проекте исследуются методы **обучения без учителя** для поиска скрытой структуры в данных о недвижимости.  
Основной акцент сделан на реализации алгоритмов кластеризации, сравнении разных подходов и анализе того, как найденные кластеры могут использоваться не только для описания структуры данных, но и как дополнительный признак в задаче регрессии.

## Цель проекта

Цель этого проекта:
- изучить основные методы кластеризации,
- реализовать часть алгоритмов с нуля,
- сравнить различные подходы к обучению без учителя на реальных данных,
- оценить качество кластеризации с помощью внутренних метрик,
- исследовать, насколько кластерные метки полезны как инструмент feature engineering для предсказания цены недвижимости.

## Датасет

В проекте используется датасет с объектами недвижимости.

Целевая переменная:
- стоимость недвижимости

Признаки включают:
- географические координаты объектов,
- числовые характеристики недвижимости,
- дополнительные признаки, описывающие параметры объектов,
- сгенерированные признаки, включая метки кластеров.

## Что реализовано и исследовано в проекте

### Алгоритмы кластеризации
- K-Means
- DBSCAN
- Agglomerative Clustering
- Gaussian Mixture Model (GMM)

### Реализации с нуля
- K-Means
- DBSCAN

### Практические эксперименты
- кластеризация объектов недвижимости разными методами,
- сравнение собственной реализации `K-Means` с `scikit-learn`,
- сравнение алгоритмов по `silhouette score` и `distortion`,
- анализ устойчивости методов на train и test выборках,
- использование кластерных меток как нового признака в модели `Lasso`,
- сравнение влияния разных методов кластеризации на качество регрессии.

## Ключевые результаты

Основные выводы проекта:
- собственная реализация `K-Means` показала результаты, близкие к библиотечной версии из `scikit-learn`,
- разные алгоритмы кластеризации по-разному описывают структуру данных,
- `DBSCAN` оказался менее устойчивым на тестовых данных в данной постановке задачи,
- `Agglomerative Clustering` и `Gaussian Mixture` показали более высокие значения `silhouette score`,
- лучший результат в downstream-задаче регрессии показали кластерные метки, полученные методом `Gaussian Mixture`,
- кластеризация может быть полезна не только как инструмент анализа данных, но и как способ улучшения признакового пространства.
