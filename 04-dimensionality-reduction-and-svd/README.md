# Понижение размерности и SVD: эксперименты и применения

В этом проекте исследуются методы понижения размерности и сингулярного разложения (**SVD**) на разных типах данных: разреженных матрицах, изображениях, видео и классических датасетах для визуализации.  
Основной акцент сделан на сравнении методов снижения размерности, анализе их практических свойств и демонстрации того, как SVD может использоваться не только для визуализации, но и для компрессии и выделения структуры в данных.

## Цель проекта

Цель этого проекта:
- изучить основные методы понижения размерности,
- сравнить линейные и нелинейные подходы к снижению размерности,
- исследовать применение `PCA`, `SVD`, `t-SNE`, `UMAP` и `LLE` на реальных данных,
- проанализировать влияние сжатия признакового пространства на качество моделей,
- показать практические применения SVD для компрессии изображений и выделения фона на видео.

## Датасеты и данные

В проекте используются несколько типов данных:

- разреженные матрицы взаимодействий в рекомендательной задаче,
- датасет **MNIST** для визуализации после снижения размерности,
- изображения для исследования компрессии с помощью SVD,
- видео для выделения фона через низкоранговое приближение,
- набор изображений лиц для дополнительного анализа в латентном пространстве.

## Что реализовано и исследовано в проекте

### Методы понижения размерности
- PCA
- SVD
- Randomized SVD
- Truncated SVD
- t-SNE
- UMAP
- Locally Linear Embedding (LLE)

### Практические эксперименты
- снижение размерности разреженных матриц признаков,
- сравнение качества моделей до и после сжатия признакового пространства,
- визуализация MNIST в двумерном пространстве,
- компрессия изображений с помощью SVD,
- выделение фоновой структуры на видео через низкоранговое приближение,
- дополнительный анализ латентных представлений лиц.

## Ключевые результаты

Основные выводы проекта:
- линейные методы, такие как `PCA` и `SVD`, хорошо подходят для сжатия признаков и базового анализа структуры данных,
- нелинейные методы, такие как `t-SNE` и `UMAP`, дают более выразительную визуализацию сложных кластерных структур,
- снижение размерности разреженных матриц может уменьшать размерность признакового пространства без существенного ускорения и улучшения качества во всех сценариях,
- сингулярное разложение эффективно работает для компрессии изображений за счёт низкорангового приближения,
- SVD можно использовать для выделения фоновой компоненты на видео,
- методы понижения размерности полезны не только для визуализации, но и для анализа, компрессии и извлечения скрытой структуры данных.
