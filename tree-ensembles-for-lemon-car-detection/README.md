# Древовидные модели с нуля для обнаружения проблемных автомобилей

В этом проекте исследуются древовидные методы машинного обучения для обнаружения проблемных подержанных автомобилей с использованием моделей, реализованных как **с нуля**, так и с помощью **популярных ML-библиотек**.  
Основной акцент сделан на понимании того, как на практике работают решающие деревья и ансамблевые методы, а также на сравнении собственных реализаций с промышленными решениями.

## Цель проекта

Цель этого проекта:
- реализовать основные древовидные модели с нуля,
- изучить, как ансамблевые методы улучшают качество предсказаний,
- сравнить собственные реализации с `scikit-learn`, `LightGBM`, `XGBoost` и `CatBoost`,
- проанализировать качество моделей на реальной задаче классификации табличных данных,
- исследовать подбор гиперпараметров для бустинговых моделей.

## Датасет

В проекте используется датасет **Don’t Get Kicked** для предсказания риска покупки проблемного автомобиля.

Целевая переменная:
- является ли автомобиль рискованным / проблемным

Признаки включают:
- характеристики автомобиля,
- информацию, связанную с покупкой,
- признаки, связанные с аукционами и дилерскими площадками,
- закодированные категориальные признаки,
- сгенерированные признаки на основе исходного датасета.

## Ключевые результаты

Основные выводы проекта:
- собственные реализации древовидных алгоритмов помогли лучше понять внутреннюю логику разбиений, уменьшения неоднородности и ансамблевого обучения,
- ансамблевые методы показали лучшее качество по сравнению с одиночным деревом решений,
- бустинговые модели продемонстрировали более сильное качество на задаче классификации табличных данных,
- промышленные библиотеки, такие как `LightGBM`, `XGBoost` и `CatBoost`, дали сильные результаты и стали хорошими бенчмарками,
- подбор гиперпараметров позволил улучшить итоговое качество бустинговых моделей,
- древовидные модели хорошо подходят для структурированных табличных данных и естественно дополняют линейные модели.
