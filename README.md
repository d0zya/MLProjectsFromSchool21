# ML Study Projects Portfolio

This repository contains a collection of machine learning projects completed during my studies.  
It combines implementations of algorithms **from scratch**, experiments with **classical machine learning**, **unsupervised learning**, and **deep learning**.

The main goal of this repository is to show both:
- understanding of machine learning theory,
- practical implementation skills using Python and popular ML libraries.

## Repository Highlights

In these projects, I worked on:
- linear models and regularization,
- classification algorithms from scratch,
- tree-based models and boosting,
- dimensionality reduction,
- clustering and unsupervised learning,
- multilayer perceptrons from scratch and in PyTorch,
- convolutional neural networks for image classification.

## Projects

| Project | Area | Key points |
|---|---|---|
| Linear Models from Scratch | Regression | Linear Regression, Ridge, Lasso, Elastic Net |
| Classification from Scratch | Classification | Logistic Regression, Naive Bayes, KNN |
| Tree-Based Models from Scratch | Classical ML | Decision Trees, Random Forest, Boosting |
| Dimensionality Reduction and SVD | Unsupervised Learning | PCA, SVD, t-SNE, UMAP |
| Unsupervised Learning and Feature Engineering | Clustering | K-Means, DBSCAN, GMM, cluster features |
| MLP from Scratch and PyTorch | Deep Learning | Backpropagation, activations, optimizers |
